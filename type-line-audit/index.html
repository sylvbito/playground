          Browser support. text-wrap: balance — Chrome 114, Firefox 121, Safari 17.5. pretty — Chrome 117, Firefox 134, Safari 26. Both are capped by the browser, not by this page: Chromium honours balance on six lines or fewer and applies pretty to a paragraph's last four lines. That is why every suggestion here is measured on your copy rather than asserted — the tool tells you when the browser shrugs.
        
    
        
    
          Nothing here is suggested on principle. Each candidate — pretty, a 68ch cap, a balanced heading — is re-measured offscreen on this copy before it is offered, and only appears if it actually removes a defect. When none of them do, the panel says so and points at the width instead.
        
    
      
    
    
    
  
    

    


    
  Every number here comes from Range.getClientRects() on the live layout — one rect per word, clustered into line boxes — so hyphenation, letter-spacing and font fallbacks are all included, because they are what the reader sees. Character measure is the real ch unit of the shipping font: measured once at a hundred em-zeroes and divided. The recommended text-wrap values are applied to a live clone of the same column, never simulated — if this browser can't do it, the preview shows that too.
