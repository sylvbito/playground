01 · one field, not two images

What it is. Every cover is a single continuous field f(x,y) passed through a cyclic palette. Rings are the contours of a p-norm distance; bands are a rotated linear ramp; chevrons are that ramp pushed by |x|.

Try it. Drag Frequency — the ring count changes with the palette spacing held constant, because spacing is a property of the field, not the colours.

02 · a real morph

What it is. The morph slider interpolates the field's parameters — the p-norm exponent (2 → 1 → 6), the radial↔chevron blend, the chevron amplitude. Nothing cross-fades; each pixel's value slides.

Try it. Jump 01 → 03 and watch a circle become a square with rounded corners on the way through a diamond.

plain JS · no deps

03 · deterministic

What it is. The seed text is hashed to a 32-bit value that drives every jitter — phase, hue offset, rotation nudge. The same seed and settings reproduce the exact same art at any export size.

Try it. Change one letter of the seed and refresh — the composition holds, the detail shifts.

04 · ship it

What it is. Export a PNG at any preset size, copy a CSS background-image data-URI, or copy the URL — every setting travels in the hash.

Try it. Copy CSS, paste it as a background-image on a Webflow card, and set background-size:cover.
