Token Debt Audit

Paste a stylesheet — a Webflow export, an inherited client site, your own legacy CSS — and it tells you what is actually in there: how many colours you really have once perceptually identical ones are merged, which spacing values fall off the grid, which type sizes are 1px apart, and a consolidated :root block built only from values you already use. Everything runs locally in the browser.
